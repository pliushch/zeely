# Zeely.ai

AI-powered avatar background generation web application.

## 🚀 Quick Start

### Install Dependencies
```bash
yarn install
```

### Run Development Server
```bash
yarn dev
```

The application will be available at: `http://localhost:5173`

### Build for Production
```bash
yarn build
```

### Preview Production Build
```bash
yarn preview
```

## 📋 About

Zeely.ai is an interactive application that allows users to:
- Generate unique avatar backgrounds from text descriptions
- Browse history of generated backgrounds
- Use credit system for generation

## 🛠 Tech Stack

- **React 19** - UI library
- **TypeScript** - type safety
- **Vite** - build tool and dev server
- **Tailwind CSS** - styling

## 📁 Project Structure

```
src/
├── app/           # Main application
├── core/          # Core logic
│   ├── common/    # Shared components and utilities
│   └── user/      # User-related logic
```
